Cara APK membaca panel ini

Semua fitur di panel disimpan di Firestore. APK cukup membaca data berikut.

system/config
  maintenance: boolean
  maintenanceMessage: string
  announcement: string
  announcementType: "info" | "warning" | "danger"
  version: string
  updateUrl: string
  changelog: string
  forceUpdate: boolean
  forceLogoutAt: waktu ISO (string)
  flags: { namaFitur: boolean }

users/{uid}
  email, name, createdAt, createdBy
  banned: boolean
  expiresAt: waktu ISO (string) atau null
  lastSeen: waktu ISO (string), ditulis oleh APK

Yang perlu dilakukan di APK

  1. Setelah login, baca users/{uid}. Kalau banned true atau expiresAt sudah lewat, langsung logout dan tampilkan alasannya.
  2. Pantau system/config secara realtime. Kalau maintenance true, tampilkan layar blokir dengan maintenanceMessage.
  3. Tampilkan announcement sebagai banner sesuai announcementType.
  4. Kalau version lebih baru dari versi terpasang, munculkan dialog update ke updateUrl. Jika forceUpdate true, dialog tidak bisa ditutup.
  5. Kalau forceLogoutAt lebih baru dari waktu login lokal, panggil signOut.
  6. Pakai flags.namaFitur untuk menyalakan atau mematikan fitur tertentu tanpa update APK.
  7. Saat APK terbuka, tulis lastSeen ke users/{uid} tiap sekitar 2 menit supaya status Online muncul di panel.
